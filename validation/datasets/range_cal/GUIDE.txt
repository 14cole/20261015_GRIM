Range Cal
---------

WORKBOOK EXAMPLE
8 GHz example; signed reference offsets +0.0125 m and -0.0125 m.
The worksheet shows 4 selected comparisons.
Yellow cells contain raw inputs. Blue cells calculate the Excel result beside the saved GRIM result.
Changing the inputs recalculates Excel only; rerun GRIM to create new outputs.

REPEAT IN GRIM
Load the .grim input files, not their CSV copies. Native files retain conventions that CSV may omit.
Measured and exact references use matching grids; correction limit 60 dB; signed offset +/-0.0125 m.
Result files are reference outputs, not additional operands. Match coordinates and polarization when comparing exports.
Plot CSV files record the numerical plot values.

SCOPE
Synthetic complex-gain correction. Each sign uses DUT, measured standard and exact standard as separate inputs.
The full specification retains 26 recorded checks. Only the selected comparisons are recalculated in this workbook.

RECORDED NOTES
Opposite declared time law: Range Cal uses GRIM's exp(+j*omega*t) phase law and will not override contradictory declared metadata (measured calibration=-jwt)
