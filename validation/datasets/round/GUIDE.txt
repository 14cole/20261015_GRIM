Round
-----

WORKBOOK EXAMPLE
Round to one decimal, using ties-to-even. Exact halfway examples: -1.25 and +0.25 deg.
The worksheet shows 8 selected comparisons.
Yellow cells contain raw inputs. Blue cells calculate the Excel result beside the saved GRIM result.
Changing the inputs recalculates Excel only; rerun GRIM to create new outputs.

REPEAT IN GRIM
Load the .grim input files, not their CSV copies. Native files retain conventions that CSV may omit.
Round azimuth/elevation/frequency to 1 decimal. Includes exact halfway values using ties-to-even rounding.
Result files are reference outputs, not additional operands. Match coordinates and polarization when comparing exports.
Plot CSV files record the numerical plot values.

RECORDED NOTES
Coordinates collapse: Rounding azimuths to 1 decimal(s) would create duplicate values. Use a higher decimal count.
Excel ROUND alone uses a different tie rule. The worksheet explicitly applies ties-to-even for halfway coordinates.
