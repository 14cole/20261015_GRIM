Crop Slice
----------

WORKBOOK EXAMPLE
Crop azimuth 10 to 30 deg, stride 2. Shown slice: elevation 5 deg, 10 GHz, HH.
The worksheet shows 6 selected comparisons.
Yellow cells contain raw inputs. Blue cells calculate the Excel result beside the saved GRIM result.
Changing the inputs recalculates Excel only; rerun GRIM to create new outputs.

REPEAT IN GRIM
Load the .grim input files, not their CSV copies. Native files retain conventions that CSV may omit.
Azimuth range 10..30 deg, stride 2; elevation +5 deg; frequency 10 GHz; polarization HH.
Result files are reference outputs, not additional operands. Match coordinates and polarization when comparing exports.
Plot CSV files record the numerical plot values.

WORKSHEET EVIDENCE
Original check indices are zero-based positions in specs/crop_slice.json.
Output 1: azimuth (deg): Excel J8; GRIM K8; percent error L8; original check 1; source result.csv row 2: azimuth
Output 1: elevation (deg): Excel J9; GRIM K9; percent error L9; original check 2; source result.csv row 2: elevation
Output 1: frequency (GHz): Excel J10; GRIM K10; percent error L10; original check 3; source result.csv row 2: frequency
Output 1: RCS (m²): Excel J11; GRIM K11; percent error L11; original check 5; source result.csv row 2: magnitude_power_linear
Output 2: azimuth (deg): Excel J12; GRIM K12; percent error L12; original check 7; source result.csv row 3: azimuth
Output 2: RCS (m²): Excel J13; GRIM K13; percent error L13; original check 11; source result.csv row 3: magnitude_power_linear
